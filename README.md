## Project description

This website introduces me, my background, interests, family, achievements, and personal growth. It is a small multi-page portfolio built with HTML, CSS, and JavaScript.

## Pages

- **Home** — introduction, clickable RSEA name, and email form
- **About Me** — interests, favorite foods, activities, and background
- **Achievements** — three pageant and school achievements
- **Family** — family members and pets, with a relationship filter
- **Growth** — skills I am developing and goals I am exploring

## Main features

- Five linked pages with navigation and previous/next links
- Click the RSEA title on the home page to show what the initials mean
- Email form checks for a non-empty, valid-looking email address and stores it in the browser's local storage
- Saved email can be removed from the same browser
- Family gallery can be filtered by relationship
- Responsive layout for desktop and mobile screens
- Local image placeholders for profile, family, and achievement photos

The email form is a front-end demonstration only. It does not send email or save addresses to a server or database. The address is stored only in the visitor's browser.

## Technologies

- HTML
- CSS
- JavaScript
- Browser local storage

No external libraries, frameworks, or database are required.


## How to run

1. Open `index.html` in a web browser.
2. Use the navigation menu to visit the other pages.
